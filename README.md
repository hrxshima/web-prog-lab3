# 2048

Браузерная игра для третьей лабораторной работы по веб-программированию. Интерфейс оформлен как винтажный пиксельный коллаж. Игра работает на HTML5, CSS3 и JavaScript с ES-модулями. Установка зависимостей и сборка не требуются.

## Правила

В начале игры на поле 4×4 появляются от одной до трёх плиток со значениями 2 или 4. При результативном ходе плитки сдвигаются в выбранном направлении. Соседние равные плитки объединяются попарно, а образовавшиеся плитки могут участвовать в следующем слиянии того же хода. За каждое слияние начисляется значение новой плитки. Например, ряд `[4, 4, 4, 4]` при движении влево превращается в `[16, 0, 0, 0]` и приносит 32 очка.

После каждого результативного хода в свободных клетках появляются одна или две новые плитки. Партия заканчивается, когда исчерпаны все ходы. Плитка 2048 сама по себе партию не заканчивает.

## Управление

| Действие | Управление |
| --- | --- |
| Сдвинуть плитки | Стрелки на клавиатуре или свайп по игровому полю |
| Отменить ход | **Undo** восстанавливает плитки и счёт до последнего результативного хода. Кнопка доступна до окончания партии |
| Начать заново | **New game** сбрасывает поле, текущий счёт и историю отмены |
| Посмотреть рекорды | **Leaderboard** показывает десять лучших результатов. Окно закрывается кнопкой × или клавишей Escape |
| Сохранить результат | После окончания партии введите имя и нажмите **Save score** |

Текущая партия, последний ход, лучший счёт и рекорды сохраняются в `localStorage`. После перезагрузки страницы можно продолжить партию с сохранённого хода. Смена партии сохраняет лучший счёт и рекорды. Хранилище привязано к адресу и профилю браузера.

## Локальный запуск

Из корня репозитория запустите статический сервер.

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Откройте [игру на локальном сервере](http://127.0.0.1:8000/). ES-модули загружаются по HTTP.

Автоматические тесты запускаются встроенным средством тестирования Node.js 22.7 или новее.

```sh
node --test
```

## Структура

| Файл или каталог | Назначение |
| --- | --- |
| `index.html` | Разметка игрового экрана и диалогов |
| `css/styles.css` | Палитра, размеры, типографика, стили поля и диалогов |
| `css/responsive.css` | Мобильная компоновка и размеры |
| `js/game.js` | Поле, каскадные ходы, начисление очков, отмена и завершение партии |
| `js/board.js` | Сетка, отображение плиток и анимации |
| `js/controls.js` | Стрелки и сенсорные жесты |
| `js/storage.js` | Запись и проверка сохранённой сессии |
| `js/leaderboard.js` | Сортировка, сохранение и отображение рекордов |
| `js/main.js` | Координация интерфейса и игровой логики |
| `assets/` | Локальные шрифты, текстура бумаги, растительный орнамент, мотылёк и favicon |
| `tests/game.test.js` | Проверки игровой логики, хранения, рекордов и определения свайпов |
