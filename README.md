# 2048

Веб-игра, разработанная в рамках третьей лабораторной работы по веб-программированию на чистых JavaScript, HTML и CSS. Игровое поле и плитки создаются через DOM API, без использования фреймворков.

Плитки можно двигать стрелками на клавиатуре или свайпами. Одинаковые плитки сливаются, а получившаяся плитка может слиться снова в том же ходу. Можно отменить последний ход, начать новую игру и сохранить результат в таблицу десяти лучших. Партия и рекорды сохраняются в `localStorage` и восстанавливаются при следующем открытии игры.

Для локального запуска выполни `python3 -m http.server 8000 --bind 127.0.0.1` из корня проекта и [открой игру](http://127.0.0.1:8000/).
